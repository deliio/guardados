# Guardados

Web app (PWA) para guardar links y capturas "para ver luego". Se clasifican solos por sitio (TikTok, LinkedIn, Instagram, YouTube, tiendas de ropa, Claude…) y las imágenes van a **Capturas**. Puedes añadir etiquetas y notas.

**Abrir:** https://deliio.github.io/guardados/

- **Android:** abre la web en Chrome → ⋮ → *Instalar aplicación*. Luego, desde cualquier app, *Compartir → Guardados*.
- **iPhone:** añádela a la pantalla de inicio y usa **+** → *Pegar del portapapeles*, o crea un Atajo que abra `https://deliio.github.io/guardados/?text=` + la entrada compartida.

Todo se guarda en el propio dispositivo (IndexedDB); nada se sube a ningún servidor. Desde el menú ⋯ puedes descargar y restaurar una copia de seguridad.

HTML, CSS y JS nativo, sin dependencias.
